## 1. Maqsad
Noto'g'ri sana yoki nom bilan yaratilgan imtihonni, noto'g'ri kiritilgan natijani, muddati xato qo'yilgan homeworkni va keraksiz kursni tuzatib/o'chirib bo'lmaydi.
"Noto'g'ri kiritdim" holati administratorni bazaga kirishga majbur qilmasligi kerak.

## 2. Hozirgi holat (kodda tekshirilgan)
- `Api/Lms/ExamsController.cs`: `GET`, `POST` (yaratish, `exams.create`), `GET {id}/results`, `POST {id}/results` (`exams.score.edit`). Tahrirlash/o'chirish **yo'q**. Yozuvlar: `ExamDto(Id, GroupId, Name, Type, Date)`, `ExamResultDto(... Listening, Reading, Writing, Speaking, Overall, StudentName)`.
- `Api/Lms/HomeworkController.cs`: `GET`, `POST` (`homework.create`), `POST {id}/submissions` (student), `GET {id}/submissions`, `GET {id}/my-submissions`, `PATCH submissions/{id}/review`. Homework tahrirlash/o'chirish **yo'q**.
- `Api/Academic/CoursesController.cs`: `GET`, `POST`, `PATCH {id}` (`courses.manage`). **`DELETE` yo'q.** Kurs guruhlarga `CourseId` bilan bog'langan; `Lead.InterestedCourse` — matn (FK emas).
- Domen: `Modules.Lms/Domain/Exam.cs` (`Exam`, `ExamResult`), `Homework.cs` (`Homework`, `HomeworkSubmission`) — `private set`, o'zgartirish metodlari yo'q.
- Natija kiritilganda `TimelineEventType.ExamResultRecorded` va `NotificationType.ExamResult` yuboriladi (namuna).

## 3. Nima qilinadi

### 3.1. Domen (migratsiya kerak emas)
`Exam.Update(name, type, date)`; `ExamResult`: mavjud ustunlarni o'zgartiruvchi `Update(...)`; `Homework.Update(title, description, type, deadline, maxScore)`.

### 3.2. Backend
| Endpoint | Ruxsat | Qoida |
|---|---|---|
| `PATCH /api/exams/{id}` | `exams.create` | nom, tur, sana. Natijalar kiritilgandan keyin ham mumkin. Guruh o'zgartirilmaydi |
| `DELETE /api/exams/{id}` | `exams.create` | faqat **natijasiz** imtihon → aks holda 409 (`blockers`: natijalar soni) |
| `DELETE /api/exams/{id}/results/{resultId}` | `exams.score.edit` | noto'g'ri kiritilgan natijani o'chiradi; timeline `EXAM_RESULT_REMOVED` (yangi tur); studentga bildirishnoma **yubormang** (xato tuzatilyapti) |
| `PATCH /api/homework/{id}` | `homework.create` | sarlavha, tavsif, muddat, maksimal ball. **Maksimal ball topshiriqlar bahosidan past bo'lmasin** → 409. Muddat o'zgarsa guruh studentlariga `NotificationType.HomeworkChanged` (yangi) |
| `DELETE /api/homework/{id}` | `homework.create` | faqat **topshiriqsiz** homework → aks holda 409 |
| `DELETE /api/courses/{id}` | `courses.manage` | guruhi (har qanday holatda) yo'q kurs → aks holda 409 + guruhlar soni |
- Scope: imtihon/homework guruhi orqali (`GroupAccess.CanAccessGroupAsync` — mavjud `POST` dagi tekshiruvni qayta ishlating); teacher faqat o'z guruhida.
- Audit: `Exam`, `ExamResult`, `Homework` `AuditedTypes` ga qo'shilsin (kim nimani o'chirgani/o'zgartirgani).

### 3.3. Frontend
- `lib/api/lms.ts`, `lib/api/academic.ts`: `updateExam`, `deleteExam`, `deleteExamResult`, `updateHomework`, `deleteHomework`, `deleteCourse`.
- `exams/page.tsx`: imtihon qatorida "Tahrirlash"/"O'chirish"; natijalar oynasida (drawer) qator oxirida ✕ (`ConfirmDialog`). 409 xabari (`ApiError.message`) ko'rsatiladi.
- Homework: `schedule/[lessonId]/page.tsx` (homework ro'yxati) da "Tahrirlash"/"O'chirish".
- Kurs: `groups/page.tsx` dagi `CourseFees` jadvalida (faqat `canManage`) "O'chirish" — guruhi bor kursda tugma o'rniga "N ta guruh bor" izohi.
- Yangi timeline va bildirishnoma turlari uchun `EVENT_CONFIG`.

## 4. Testlar — `LmsTests.cs` ga +~10 (yoki `LmsEditTests.cs`)
1. Imtihon tahrirlash; natijali imtihonni o'chirish → 409; natijasizini o'chirish → 204. 2. Natijani o'chirish → timeline'da `EXAM_RESULT_REMOVED`.
3. Homework tahrirlash; maksimal ballni topshiriq bahosidan pastga tushirish → 409; muddat o'zgarganda bildirishnoma. 4. Topshiriqli homeworkni o'chirish → 409.
5. Kursni o'chirish: guruhsiz → 204; guruhli → 409. 6. Teacher boshqa o'qituvchining guruhi imtihoniga → 403; student → 403.
7. Audit jurnalida yangi turlar.
