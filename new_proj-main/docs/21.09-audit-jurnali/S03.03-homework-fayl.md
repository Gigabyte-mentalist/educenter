## 1. Maqsad
`HomeworkType.FileUpload` enum'da bor, lekin fayl yuklash yo'q: student faqat **matn** yoki **tashqi havola** yubora oladi, o'qituvchi topshiriq fayli (worksheet, audio) biriktira olmaydi.
Fayl infratuzilmasi boshqa joylarda tayyor (resurslar, student hujjatlari, chat, bilim bazasi) — faqat homework'ga ulanmagan.

## 2. Hozirgi holat (kodda tekshirilgan)
- `Modules.Lms/Domain/Homework.cs`: `Homework(LessonId, Title, Description, Type, Deadline, MaxScore)`; `HomeworkSubmission(HomeworkId, StudentId, ContentUrl?, ContentText?, SubmittedAt, Score?, Feedback?, ReviewedBy?, ReviewedAt?)`.
- `Api/Lms/HomeworkController.cs`: `SubmitHomeworkRequest(string? ContentUrl, string? ContentText)` — `POST {id}/submissions` (JSON). `CreateHomeworkRequest(LessonId, Title, Description, Type, Deadline, MaxScore)` — `POST` (JSON).
- **Namuna:** `Api/Students/StudentDocumentFileStorage.cs` + `StudentDocumentsController.Upload` (multipart, `Validate` → `SaveAsync` → xato bo'lsa `Delete`), `Api/Lms/ResourceFileStorage.cs`. Frontend: `uploadStudentDocument` (`FormData`), `components/LessonResources.tsx`.
- AI Writing baholash (`Ai/Writing/*`) `HomeworkSubmission` matniga tayanadi (`HomeworkSubmissionId`) — **faqat fayl yuborilgan** topshiriq bu oqimni buzmasligi kerak (matn bo'sh bo'lsa baholash taklif qilinmaydi).

## 3. Nima qilinadi

### 3.1. Domen va migratsiya
`Homework` ga (o'qituvchining topshiriq fayli) va `HomeworkSubmission` ga (studentning javobi) bir xil to'rtlik: `AttachmentKey` (64), `AttachmentName` (255), `AttachmentContentType` (128), `AttachmentSize` (`long?`).
Fabrika/metod: `Homework.AttachFile(...)`, `HomeworkSubmission.WithFile(...)`. Migratsiya **`AddHomeworkAttachments`**.
`StudentDocument` dagi CHECK-constraint naqshini ko'rib chiqing (fayl **yoki** havola) — bu yerda ixtiyoriy: submission "matn + fayl" bo'lishi mumkin.

### 3.2. Backend
- Yangi `Api/Lms/HomeworkFileStorage.cs` (`StudentDocumentFileStorage` nusxasi): papka `App_Data/homework`, **20 MB** (audio uchun), `AllowedTypes`: pdf, doc(x), ppt(x), xls(x), png/jpg/webp, mp3/m4a/wav, txt. `Program.cs` da `AddScoped` + `Configure<HomeworkFileOptions>(GetSection("Homework"))`.
- Endpointlar:

| Endpoint | Ruxsat | Nima qiladi |
|---|---|---|
| `POST /api/homework/upload` | `homework.create` | multipart: `lessonId`, `title`, `description?`, `type`, `deadline`, `maxScore`, `file` — fayl bilan homework yaratadi (mavjud JSON `POST` qoladi, faylsiz) |
| `GET /api/homework/{id}/attachment` | `homework.view` | topshiriq faylini beradi (scope: guruh bo'yicha) |
| `POST /api/homework/{id}/submissions/upload` | `homework.submit` | multipart: `file` va ixtiyoriy `contentText`. Muddat/qayta topshirish qoidalari mavjud JSON endpointdagi bilan **bir xil** |
| `GET /api/homework/submissions/{id}/attachment` | `homework.view` | javob fayli. **Student faqat o'zinikini**, o'qituvchi/administrator o'z scope'idagilarini; ota-ona farzandiniki |
- `[RequestSizeLimit(22 * 1024 * 1024)]`. Bo'sh fayl va ruxsat etilmagan tur → 400 (`files.Validate`).
- Scope tekshiruvi mavjud `HomeworkController` metodlaridagi bilan bir xil (`CanAccessGroupAsync` / `CanAccessStudentAsync`) — **nusxa qiling, yangidan o'ylamang**.
- Yangi fayl qo'yilganda avvalgisi diskdan o'chiriladi (student qayta topshirsa); entity o'chirilsa fayl ham.

### 3.3. Frontend
- `lib/api/lms.ts`: `createHomeworkWithFile`, `submitHomeworkFile`, `downloadHomeworkAttachment` (`apiFetchBlob`, asl nom bilan saqlash — `LessonResources.tsx` dagi blob-yuklab olish).
- Homework yaratish formasiga "Fayl biriktirish" (ixtiyoriy, hajm/tur oldindan tekshiriladi: `lib/format-bytes.ts`). Student topshirish oynasiga "Fayl yuklash" (matn bilan birga).
- O'qituvchi tekshirish ro'yxatida javob faylini yuklab olish; student sahifasida (`StudentLearningTabs` homework tab) o'z faylini ko'rish.

## 4. Testlar — `HomeworkFilesTests.cs` (~8)
1. O'qituvchi fayl bilan homework yaratadi, student yuklab oladi (baytlar bir xil). 2. Student fayl topshiradi; o'qituvchi yuklab oladi; ota-ona farzandiniki.
3. **Boshqa studentning javobini olishga urinish → 403.** 4. Hajm chegarasi (20 MB dan katta) → 400/413; ruxsat etilmagan tur (`.exe`) → 400.
5. Qayta topshirish eski faylni almashtiradi (diskda bitta). 6. Fayl-only topshiriqda AI Writing baholash taklif qilinmaydi/xato bermaydi.
7. Teacher boshqa guruh homeworkiga → 403. 8. Mavjud JSON topshirish testlari o'zgarishsiz yashil.
