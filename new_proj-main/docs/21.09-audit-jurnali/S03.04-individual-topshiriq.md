## 1. Maqsad
Homework faqat `LessonId` ga bog'lanadi → **har doim butun guruhga**. TZ §16: "group/student assignment" — zaif student uchun alohida topshiriq berish mumkin emas.

## 2. Hozirgi holat (kodda tekshirilgan)
`Homework` da studentga bog'lovchi hech narsa yo'q. "Studentga berilgan homework" har joyda **guruhdagi barcha homework** deb hisoblanadi. Quyidagi joylar shunday hisoblaydi va **hammasi o'zgarishi kerak**

## 3. Nima qilinadi
- **Domen:** yangi `HomeworkTarget(Id, OrganizationId, HomeworkId, StudentId)` (`Modules.Lms/Domain/Homework.cs`; unique index `(HomeworkId, StudentId)`). **Qator yo'q = butun guruh** (orqaga moslik: mavjud homeworklar o'zgarishsiz ishlaydi).
  Migratsiya **`AddHomeworkTargets`**.
- **Yordamchi:** `Api/Lms/HomeworkQueries.cs` — `IQueryable<Homework> AssignedTo(this IQueryable<Homework> homework, AppDbContext db, Guid studentId)`:
  `h => !db.HomeworkTargets.Any(t => t.HomeworkId == h.Id) || db.HomeworkTargets.Any(t => t.HomeworkId == h.Id && t.StudentId == studentId)`. 2-bo'limdagi **har bir** joyda shuni qo'llang (yoki ataylab qoldirsangiz sababini izohga yozing).
- **Backend:** `CreateHomeworkRequest` (va S03.03 dagi multipart) ga `List<Guid>? StudentIds`. Berilsa: har biri shu guruhning **faol** studenti bo'lishi shart (aks holda 400 + ro'yxat); `HomeworkTarget` qatorlari yoziladi; bildirishnoma (`HomeworkCreated`) **faqat** maqsadli studentlarga (+ ota-onalari).
  `POST {id}/submissions`: maqsadli bo'lmagan student topshira olmasin → 403. `HomeworkDto` ga `StudentIds` (bo'sh = butun guruh) qo'shing — faqat `homework.create` egalariga; student/ota-ona `targeted: bool` ni ko'rishi yetarli.
- **Frontend:** homework yaratish formasiga "Kimga: butun guruh / tanlangan studentlar" (ko'p tanlov: `GET /api/groups/{id}/students`); ro'yxatda "Individual" belgisi (`Badge`).

## 4. Testlar — `LmsTests.cs` ga +~6
1. Bitta studentga topshiriq: faqat u ko'radi (`GET /api/homework`), boshqa student ko'rmaydi va topshira olmaydi (403). 2. Maqsadli bo'lmagan studentning `homeworkCompletionRate` i **tushmaydi**.
3. Bildirishnoma faqat maqsadliga. 4. Guruhda faol bo'lmagan student id → 400. 5. `StudentIds` bo'sh/berilmagan → butun guruh (mavjud xatti-harakat). 6. `FollowUpRules.RunHomeworkSignalsAsync` maqsadli bo'lmagan homeworkni hisoblamaydi.
