## 1. Maqsad
TZ §7 sakkizta raqamni talab qiladi: Listening 7.0 · Reading 6.5 · Writing 5.5 · Speaking 6.0 · Grammar 71% · Vocabulary 84% · Attendance 91% · Homework 78%.
Hozir `GET /api/students/{id}/overview` faqat oxirgi ikkitasini qaytaradi.

## 2. Hozirgi holat (kodda tekshirilgan)
- `StudentsController.GetOverview` (`students.view`): `attendanceRate`, `homeworkCompletionRate` (ikkalasi 0–100, bitta raqam).
- `ExamResult`: Listening/Reading/Writing/Speaking/Overall (band), + S04.01 dan Grammar/Vocabulary (foiz). `Exam.Date`, `Exam.Type` (`Placement, Unit, Monthly, MockIelts, Final, Custom`).
- `WritingEvaluation` (`Modules.Ai/Domain/WritingEvaluation.cs`): `EstimatedBand`, `TaskResponseBand`, `CoherenceBand`, `LexicalBand`, `GrammarBand` + o'qituvchi tuzatishlari `TeacherBand`, `TeacherGrammarBand`… (o'qituvchi bahosi AI'dan ustun — mavjud qoida).
  Baholashlar **xodimga ko'rsatiladi** (`ai.writing.review`).
- ⚠️ **Speaking mashqi shaxsiy:** `SpeakingController` izohi — "Sessions, recordings and assessments belong to the account that made them; nothing here is shared with staff". `SpeakingSession.EstimatedBand` ni xodim ko'radigan profilga **kiritmang**.
  Profilda Speaking = faqat `ExamResult.Speaking`. (Student o'z ko'rinishida AI mashqi bandini alohida ko'rishi mumkin — S04.03 da qaror.)
- `StudentLearningController`: `attendance`, `homework`, `exams` endpointlari (`CanReadAsync` = `CanAccessStudentAsync` + tashkilot) — naqsh.

## 3. Nima qilinadi

### 3.1. Backend — `GET /api/students/{id}/learning-profile` (`students.view`, `CanAccessStudentAsync`)
Yangi tuzilma hisoblanadigan, **yangi jadval yo'q**:
```
LearningProfileDto(
  SkillDto Listening, Reading, Writing, Speaking,     // band: Value (decimal?), SampleSize (int), Trend (-1/0/+1/null)
  PercentDto Grammar, Vocabulary,                     // foiz: Value, SampleSize, Trend
  PercentDto Attendance, HomeworkCompletion)
```
| Ko'rsatkich | Manba | Qoida |
|---|---|---|
| Listening / Reading / Speaking | `ExamResult` (oxirgi **5** ta) | og'irlikli o'rtacha: yangisi kuchliroq (masalan og'irliklar 5,4,3,2,1); `SampleSize` = ishlatilgan natijalar soni |
| Writing | `ExamResult.Writing` **va** `WritingEvaluation` | ikkalasi birga: AI bahosi o'rniga o'qituvchi tuzatgani (`TeacherBand ?? EstimatedBand`); oxirgi 5 ta umumiy |
| Grammar % / Vocabulary % | `ExamResult.Grammar/Vocabulary` + `HomeworkType.Grammar/Vocabulary` topshiriq baholari (`Score / Homework.MaxScore × 100`) | bir xil og'irlikli o'rtacha |
| Attendance % | `Attendance` (mavjud hisob — `Present/Online/Late` = kelgan; S02.02 dan keyin bekor qilingan darslarsiz) | `StudentsController` dagi formula bilan **bir xil** bo'lsin (yoki o'sha kodni umumiy yordamchiga chiqaring) |
| Homework % | `HomeworkSubmission` / tayinlangan homework (S03.04 dan keyin `AssignedTo` bilan) | mavjud formula |
- **Trend:** oxirgi 3 natija o'rtachasi va undan oldingi 3 tasi farqi (±0.25 band / ±3 foiz dan kichik → `0`). Ma'lumot yetmasa `null`.
- **Ma'lumot yetmasa `Value = null`** — soxta raqam ko'rsatilmaydi (Teacher Performance va Group Recommendation'dagi qaror). `SampleSize` har raqam yonida: "2 ta natijadan" va "20 ta natijadan" bir xil ishonchda emas.
- Hisoblash `Api/Students/LearningProfileCalculator.cs` (sof funksiyalar: `WeightedAverage`, `Trend`) — **unit test qilinadigan** qilib yozing; S04.05 va S05.03 shuni qayta ishlatadi.
