## 1. Maqsad
`org.settings.edit` ruxsati seed qilingan, lekin **hech qaysi endpoint uni ishlatmaydi**. Tashkilot nomi, logo, valyuta, ish vaqti, brend rangi — hech qayerda tahrirlanmaydi (TZ §48 "Tenant-level config / branding").

## 2. Hozirgi holat (kodda tekshirilgan)
- `Modules.Organizations/Domain/Organization.cs`: `Name`, `TenantSlug`, **`BrandingConfigJson` (mavjud, lekin hech qayerda ishlatilmaydi)**, `AiLimitsConfigJson` (ishlatiladi: `Api/Ai/AiLimits.cs`, `AiController` — katalog + `Resolve` (qiymatni katalog oralig'iga qisadi) naqshi).
- `Api/Organizations/OrganizationsController.cs`: `GET {id}` (`branch.view`), `POST` (`branch.create`). `PATCH` yo'q. `Branch` da `Timezone` bor (vaqt zonasi filial darajasida).
- Frontend: sozlamalar sahifalari — `app/(admin)/settings/notifications/`. Ranglar: `lib/theme.ts` (tema), CSS tokenlar (`--color-brand-*`).
- Pul birligi "so'm" `formatMoney` (`lib/api/finance.ts`) va `Invoice.Currency` (matn) — qattiq yozilmagan, lekin markaz tanlay olmaydi.

## 3. Nima qilinadi
- **Saqlash:** yangi ustun **ochmang** — mavjud `BrandingConfigJson` (logo kaliti, brend rangi) va yangi `SettingsJson` (`string?`) yoki bir nechta typed ustun (`Currency`, `Locale`, `WorkdayStart/End` — so'rovlarda ishlatilmasa JSON yetarli). Tavsiya: **`AiLimits` naqshi** — kod ichida `OrganizationSettingsCatalog` (kalit, standart, chegara) va `Resolve(json)` (noma'lum/oralig'idan tashqari qiymat e'tiborsiz). Migratsiya faqat `LogoKey` kabi yangi ustun kerak bo'lsa (**`AddOrganizationSettings`**).
- **Sozlamalar:** `Name`; `Currency` (`UZS` standart; `formatMoney` shundan foydalansin — frontend `GET /api/organizations/current` javobidan); `WorkdayStart/End` (jadval formasi uchun standart); `BrandColor` (HEX, kontrast tekshiruvi: oq matn 4.5:1 — yomon bo'lsa 400); logo (rasm ≤ 1 MB, png/jpg/webp — **SVG yo'q**, `UserPhotoStorage`/`StudentDocumentFileStorage` naqshi, `App_Data/org-logo`).
- **Endpointlar:** `GET /api/organizations/current` (`branch.view` — hamma xodim; student/ota-ona ham logoni ko'radi → `[Authorize]` va faqat ommaviy maydonlar: nom, logo, brend rangi), `PATCH /api/organizations/{id}` (`org.settings.edit`, faqat o'z tashkiloti), `POST/DELETE /api/organizations/{id}/logo`, `GET /api/organizations/{id}/logo` (bearer; kesh `private, max-age=3600`). Audit: `Organization` allaqachon `AuditedTypes` da.
- **Brend rangi ta'siri:** `lib/theme.ts`/layout'da `--color-brand-*` o'zgaruvchilarini kirish paytida `organization.brandColor` dan hosil qilingan ramp bilan almashtirish (tungi rejimda ramp teskari bo'ladi — mavjud mexanizmni buzmang; **faqat `brand-solid` va asosiy 500–700 tugunlarini** almashtiring, qolganini hisoblang yoki `color-mix` ishlating). Brend rangi berilmagan bo'lsa hozirgi (yashil) qoladi.
- **Frontend:** `app/(admin)/settings/organization/page.tsx` (faqat `can("org.settings.edit")`; `lib/nav.ts` da "Tashkilot" guruhida havola), forma: nom, valyuta, ish vaqti, brend rangi (`<input type="color">` + HEX), logo yuklash. Logo sidebar (`(admin)/layout.tsx`) va login sahifasida.

## 4. Testlar — `OrganizationSettingsTests.cs` (~6)
1. SA sozlamalarni o'zgartiradi, `GET current` qaytaradi. 2. Administrator/teacher `PATCH` → 403. 3. Noto'g'ri HEX/valyuta → 400. 4. Logo: yuklash/olish/o'chirish; `.svg`, 1 MB dan katta → 400. 5. Student `GET current` — faqat ommaviy maydonlar. 6. Boshqa tashkilot id → 404/403.
