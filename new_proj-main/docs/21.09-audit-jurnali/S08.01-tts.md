## 1. Maqsad
TZ §34 pipeline: `Microphone → VAD → STT → LLM → Response → **TTS** → Speaker`. STT (Whisper) va LLM bor, **TTS yo'q** — imtihonchining savoli faqat matn. Bu qadamda savol ovozda o'qiladi.

## 2. Hozirgi holat (kodda tekshirilgan)
- `Api/Ai/Providers/SpeechToTextProvider.cs`: `ISpeechToTextProvider` (`Name`, `TranscribeAsync`), `WhisperAsrProvider`; `AiProviderRegistry` (`Providers/AiProviderRegistry.cs`): `_activeSpeech`, `SpeechTarget`, `Chain(AiTaskKind.Transcription)`; `FakeSpeechToTextProvider` (test).
- **`AiTaskKind.SpeechSynthesis` enum'da allaqachon ajratilgan** (`Modules.Ai/Domain/AiRequest.cs`) — TTS shu naqshda ulanadi (router zanjiri, limit, jurnal).
- `AiGateway.TranscribeAsync` — STT ham gateway orqali (limit/fallback/usage). `AiOptions` da provayder turlari: `Fake, OpenAiCompatible, Ollama, WhisperAsr`; marshrutlar `Ai:Routes` (`appsettings.json`).
- `Api/Ai/Speaking/SpeakingController.cs`: `GET sessions/{id}/turns/{turnId}/audio` — **studentning javob yozuvi**. Savol matni `SpeakingTurn.Question`. `Api/Ai/Speaking/SpeakingAudioStorage.cs` — diskda audio (`App_Data`).
- Frontend `app/(admin)/ai/speaking/page.tsx` — yozuv (MediaRecorder), savol matni. `docker-compose.yml`: `ollama`, `whisper` (`onerahmet/openai-whisper-asr-webservice`, host `19000`); host'da `9000` — Docker Desktop'ga tegishli.

## 3. Nima qilinadi
- **Interfeys:** `ITextToSpeechProvider { string Name; Task<SpeechResult> SynthesizeAsync(string text, string voice, string language, CancellationToken ct); }` (`SpeechResult(byte[] Audio, string ContentType)`), `AiProviderType` ga yangi tur, `AiProviderRegistry` ga `SpeechSynthesis` zanjiri (`Chain(AiTaskKind.SpeechSynthesis)`), `AiGateway.SynthesizeAsync` (limit/jurnal — `TranscribeAsync` nusxasi; **TTS ovoz hajmi emas, belgi soni** jurnalga).
- **Provayder (tavsiya):** OpenAI-mos TTS endpointi (`POST /v1/audio/speech`) — mahalliy Piper ovozlarini shu protokolda beradigan servis (masalan `openedai-speech` konteyneri — **nomi va tegini ishga tushirishdan oldin tekshiring**) — bo'lsa keyinchalik pullik provayderga almashtirish `BaseUrl`+kalit bilan bo'ladi. `OpenAiCompatibleTtsProvider` yozing. `docker-compose.yml` ga servis (nomi `educenter-tts`, **boshqa loyihalar konteynerlariga tegmang**; host porti bo'sh bo'lsin — 9000 band).
  Muqobil (backend'siz, birinchi tez versiya): brauzer `speechSynthesis` — faqat foydalanuvchi ruxsat bersa; **TZ arxitekturasi (`ITextToSpeechProvider`) baribir bajariladi**, brauzer ovozi fallback bo'lib qoladi.
- **Sozlama:** `Ai:Providers:<nom>` (`Type`, `BaseUrl`, `ChatModel` o'rniga `SpeechVoice`, `Enabled`), marshrut `SpeechSynthesis`; **standart o'chiq** (provayder bo'lmasa savol matni bilan ishlayveradi — xato emas).
- **Backend:** `GET /api/ai/speaking/sessions/{id}/turns/{turnId}/question-audio` (`ai.speaking.use`, faqat sessiya egasi): birinchi so'rovda sintez qiladi va `SpeakingAudioStorage` ga **keshlaydi** (kalit: savol matni xeshi + ovoz) — bir xil savol qayta sintez qilinmaydi; provayder yo'q/xato → 503 `{ error }` (frontend matnga qaytadi). Savol matni **o'qiladigan** kirish sifatida `AiInputValidator` dan o'tadi (savol allaqachon model chiqishi — uzunlik chegarasi `SpeakingTurn.MaxQuestionLength`).
- **Frontend:** `ai/speaking/page.tsx` — savol yonida ▶ tugmasi; "Savolni avtomatik o'qish" sozlamasi (`localStorage`, `try/catch`); ijro tugamaguncha yozuv tugmasi o'chirilgan (ovoz mikrofonga tushmasin); 503 → jimgina matn. Brauzer autoplay siyosati: birinchi ijro foydalanuvchi bosishidan keyin.
