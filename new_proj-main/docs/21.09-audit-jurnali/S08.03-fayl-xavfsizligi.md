## 1. Maqsad
TZ §38 (RAG poisoning himoyasi) hujjat qabuli 8 qadam: file validation → **malware/security scan** → parsing → injection scan → access classification → chunking → embedding → vector storage. **2-qadam yo'q**. Shuningdek yuklangan fayl turi faqat kengaytma bo'yicha tekshiriladi.

## 2. Hozirgi holat (kodda tekshirilgan)
- Yuklash yo'llari (har biri o'z `*FileStorage` klassi bilan, `AllowedTypes` **kengaytma** oq ro'yxati): chat (`Api/Chat/ChatFileStorage.cs`), dars resurslari (`Api/Lms/ResourceFileStorage.cs`), student hujjatlari (`Api/Students/StudentDocumentFileStorage.cs`), bilim bazasi (`Api/Ai/Knowledge/KnowledgeFileStorage.cs`), speaking audio (`SpeakingAudioStorage.cs`); S03.03/S04.04/S05.02/S07.01 dan keyin: homework, foydalanuvchi foto, o'qituvchi hujjatlari, tashkilot logosi.
- `Api/Ai/Knowledge/KnowledgeIngestor.cs` — pipeline: parsing → **prompt-injection skani (karantin)** → chunking → embedding; `DocumentTextExtractor.cs` — faqat `.pdf`, `.docx` (+ matn). `.pptx`, `.xlsx`, `.txt`, `.md` qo'llanmaydi.
- Malware skaneri **yo'q**. Fayl turi mazmuni (magic bytes) tekshirilmaydi: `.exe` ni `.pdf` deb nomlasa o'tadi.

## 3. Nima qilinadi
- **`IFileScanner`** (`Api/Files/`): `Task<ScanResult> ScanAsync(Stream, string fileName, CancellationToken)` (`Clean`, `Infected(signature)`, `Unavailable`). Implementatsiyalar: `ClamAvScanner` (TCP **INSTREAM**, `clamd` `:3310`; chunk'lab yuborish, `Files:Scanner:Host/Port/TimeoutSeconds`), `NoopFileScanner` (faqat Development; **Production'da** `Files:Scanner:Required=true` va skaner yo'q/`Unavailable` → **yuklashni rad etadi** — fail-closed; `Program.cs` da konfiguratsiya tekshiruvi S09.01 dagi validatsiyaga qo'shiladi).
  `docker-compose.yml` ga `clamav` (`clamav/clamav` — imzolar bazasi yuklanguncha ~1–2 daqiqa; healthcheck) — **nom/portni boshqa loyihalar bilan to'qnashtirmang**.
- **Umumiy yuklash oqimi:** har `*FileStorage.Validate/SaveAsync` **ichida** skaner chaqiriladi (yoki ularning umumiy asos klassi/`IFileGuard.CheckAsync(IFormFile, AllowedTypes)`): (1) hajm, (2) kengaytma oq ro'yxati, (3) **magic bytes** (`FileSignatures`: pdf `%PDF`, png `89 50 4E 47`, jpg `FF D8 FF`, webp `RIFF….WEBP`, docx/pptx/xlsx `PK` (zip) + ichida `[Content_Types].xml`, mp3 `ID3`/`FF FB`, m4a `ftyp`, wav `RIFF….WAVE`, txt/md — UTF-8 matn), (4) skaner. Xato xabarlari o'zbekcha va aniq ("Fayl mazmuni kengaytmasiga mos emas", "Fayl xavfli deb topildi"); zararli fayl **saqlanmaydi**.
- **Bilim bazasi:** skaner "Uploaded → Processing" oldida; zararli → hujjat `Quarantined` (mavjud karantin holati bilan bir xil ko'rinish, sabab "malware"). `DocumentTextExtractor` ga `.pptx` (slayd matni), `.txt`, `.md` qo'shing (xavfsiz parslash: zip-bomba chegarasi — ochilgan hajm ≤ 50 MB, fayllar soni ≤ 1000).
- **Audit/log:** rad etilgan zararli yuklash `logger.LogWarning` (fayl nomi, foydalanuvchi, imzo nomi; fayl mazmuni yo'q). Zararli topilishi Developer monitoringida ko'rinsin (ixtiyoriy).
- **Sozlama:** `Files:Scanner` (`Provider: none|clamav`, `Required`, `Host`, `Port`).

## 4. Testlar — `FileSecurityTests.cs` (~7; skaner uchun **`FakeFileScanner`**: EICAR satrini "infected" deb qaytaradi — haqiqiy ClamAV testda yo'q)
1. EICAR bo'lgan fayl har yuklash yo'lida (resurs, student hujjati, chat, bilim bazasi) rad etiladi va diskda qolmaydi. 2. **Kengaytmasi almashtirilgan** fayl (`.exe` → `.pdf`) rad etiladi. 3. To'g'ri pdf/png/docx o'tadi.
4. Skaner `Unavailable` + `Required=true` → yuklash rad etiladi; `Required=false` → o'tadi (dev). 5. `.pptx` va `.txt` bilim bazasida parslanadi. 6. Zip-bomba chegarasi (juda ko'p fayl) → rad. 7. Mavjud yuklash testlari yashil.
