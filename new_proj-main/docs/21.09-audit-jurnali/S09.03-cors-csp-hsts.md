## 1. Maqsad
CORS hamma originga ochiq; CSP, HSTS, Permissions-Policy yo'q.

## 2. Hozirgi holat (kodda tekshirilgan)
- `Api/Program.cs`: `AddCors` → `policy.SetIsOriginAllowed(_ => true).AllowAnyHeader().AllowAnyMethod()` (izoh: "Dev-only… production uchun toraytiring", lekin muhitga qarab ajratilmagan). Sarlavhalar middleware'i: `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: strict-origin-when-cross-origin` — **faqat API javoblarida**. `app.UseHttpsRedirection()`.
- Frontend `frontend/next.config.ts` — faqat `allowedDevOrigins`; sarlavhalar yo'q. **CSP HTML beradigan frontend'da kerak** (API JSON beradi — unda CSP kam ta'sir qiladi).
- Autentifikatsiya: bearer token (`Authorization` sarlavhasi), **cookie yo'q** — CSRF xavfi yo'q (kodda izohlangan); token `localStorage` da (XSS bo'lsa o'g'irlanadi — shuning uchun CSP muhim).
- SignalR: WebSocket (`wss://…/hubs/chat`), token `access_token` query'da.

## 3. Nima qilinadi
- **CORS:** `Cors:AllowedOrigins` (massiv, konfiguratsiya). **Development**: bo'sh bo'lsa hozirgi keng xatti-harakat (LAN/Tailscale hostlari — `next.config.ts` dagi `allowedDevOrigins` bilan izchil) — aniq ro'yxat berilgan bo'lsa ro'yxat. **Production/Staging**: bo'sh ro'yxat = **ishga tushmaslik** (`StartupValidation`, S09.01). `WithOrigins(...)`, `AllowCredentials` **yo'q**, `WithExposedHeaders("Content-Disposition")` (fayl yuklab olish nomi uchun — tekshiring), preflight keshi `SetPreflightMaxAge(1 soat)`.
- **API sarlavhalari (qo'shimcha):** `Strict-Transport-Security: max-age=31536000; includeSubDomains` — **faqat HTTPS orqasida** (`context.Request.IsHttps` yoki `X-Forwarded-Proto` — `ForwardedHeaders` middleware'ini yoqing va ishonchli proxy'larni sozlang: `KnownProxies`/`ForwardedHeadersOptions`, aks holda `IsHttps` noto'g'ri); `Permissions-Policy: camera=(), geolocation=(), microphone=(self)` (Speaking mikrofoni!); `Cross-Origin-Opener-Policy: same-origin`; `X-Frame-Options` saqlansin.
- **Frontend CSP (`next.config.ts` → `headers()`):** dastlab **`Content-Security-Policy-Report-Only`** (bir hafta kuzating), keyin majburiy. Boshlang'ich: `default-src 'self'`; `script-src 'self' 'unsafe-inline'` (Next.js inline skriptlari va tema skripti — `nonce` ga o'tish keyingi iteratsiya; dev'da `'unsafe-eval'` kerak, faqat `NODE_ENV=development`); `style-src 'self' 'unsafe-inline'` (Tailwind/Next); `img-src 'self' data: blob:` (foto/blob'lar); `media-src 'self' blob:` (speaking audio); `connect-src 'self' <API origin> wss://<API host>` (env'dan: `NEXT_PUBLIC_API_URL`); `font-src 'self' data:`; `frame-ancestors 'none'`; `base-uri 'self'`; `form-action 'self'`; `object-src 'none'`. Tashqi CDN/shrift ishlatilmayotganini `grep` bilan tekshiring (Google Fonts bo'lsa `font-src`/`style-src` kengayadi — `next/font` odatda self-host qiladi).
- **HSTS frontend'da:** TLS'ni tugatuvchi joyda (reverse proxy — S09.12); Next.js `headers()` ga ham qo'shish mumkin, lekin faqat production build va HTTPS.
- Hujjat: `docs/` ga qisqa "Sarlavhalar va CORS siyosati" bo'limi (S09.10 README ga havola).

## 4. Testlar
- `SecurityHeadersTests.cs` (~5): API javobida `nosniff`, `DENY`, `Permissions-Policy`, `Referrer-Policy` bor; HTTPS'siz **HSTS yo'q**, `X-Forwarded-Proto: https` bilan bor (ForwardedHeaders sozlangan bo'lsa); CORS: ruxsat etilgan origin `Access-Control-Allow-Origin` oladi, begona origin **olmaydi** (Production konfiguratsiya bilan `WebApplicationFactory` — `Cors:AllowedOrigins` berilgan); preflight (`OPTIONS`) to'g'ri.
- Brauzerda (Playwright): CSP `Report-Only` bilan asosiy sahifalar (login, dashboard, speaking mikrofon, chat websocket, fayl yuklash/blob rasm) **konsol xatosisiz** (CSP violation yo'q) — natijani `docs/09` ga yozing; majburiy rejimga o'tishdan oldin foydalanuvchi bilan tasdiqlang.

## 5. Boshlashdan oldin o'qing
`Api/Program.cs` (CORS va sarlavha bloklari), `frontend/next.config.ts`, `frontend/src/lib/api-client.ts` (API origin qanday aniqlanadi), `frontend/src/app/layout.tsx` (tema inline skripti), `Api/Bootstrap/StartupValidation.cs` (S09.01). TZ: `docs/00_TZ.md` qator 1686–1700 (§49 Protection).

## 6. Qabul mezoni
- [ ] Production'da faqat ruxsat etilgan originlar; HSTS/Permissions-Policy/COOP sarlavhalari; frontend CSP (avval Report-Only) va konsolda buzilishlar yo'q. Testlar, `tsc`, `eslint` yashil; `docs/09` ga band.

## 7. Xavflar
- **Juda qattiq CSP** mikrofon/blob/websocket'ni sindirishi mumkin — Report-Only bosqichi shuning uchun. `frame-ancestors 'none'` bilan `X-Frame-Options` ziddiyatsiz.
