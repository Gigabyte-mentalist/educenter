## 1. Maqsad
Backend 175+ integratsiya testi bilan qoplangan, frontend **0 ta** (`package.json` da `test` skripti yo'q). Eng qimmat besh oqim (buzilsa markaz ishlay olmaydi) avtomatik tekshirilsin.

## 2. Hozirgi holat
- `frontend/package.json`: test skripti yo'q. Bu sessiyaning o'zi Playwright'ni `playwright-core` orqali qo'lda ishlatgan (`_naqshlar.md` §8) — bu **ad-hoc tekshiruv**, repoga yozilgan test emas.
- Dev serverlar: frontend `:3002`, API `:5167` (`bash backend/scripts/dotnet-in-docker.sh api`). Demo login: `_naqshlar.md` §7 dagi foydalanuvchilar.

## 3. Nima qilinadi
- `npm install -D @playwright/test`, `frontend/playwright.config.ts` (`baseURL: http://localhost:3002`, `use: { screenshot: 'only-on-failure' }`, CI'da `retries: 2`).
- `frontend/e2e/` papkasi, testlar (har biri mustaqil `test.describe`, o'z ma'lumotini yaratadi — `Date.now()`/`crypto.randomUUID()` bilan noyob email/nom, boshqa testga tegmaydi):
  | Fayl | Nima tekshiradi |
  |---|---|
  | `login.spec.ts` | to'g'ri/noto'g'ri login, rolga qarab `/dashboard` ko'rinishi farqi (superadmin vs student) |
  | `attendance.spec.ts` | teacher: dars sahifasi → davomat belgilash → saqlash → qayta ochilganda saqlangan |
  | `payment.spec.ts` | administrator: student profilida to'lov qabul qilish → balans yangilanishi |
  | `lead-to-student.spec.ts` | operator: yangi lid → trial → konvertatsiya → student yaratilgani (S01.01 dan keyingi `StudentCreateDrawer` bilan emas, mavjud `ConvertLeadDrawer` bilan) |
  | `student-create.spec.ts` | administrator: `/students` → "Yangi student" → forma → yaratilgan student ro'yxatda (S01.01 — bu sessiyada allaqachon qo'lda sinalgan, endi **repoga yoziladi**) |
- `package.json`: `"test:e2e": "playwright test"`. CI (S09.10) ga **ixtiyoriy** qo'shiladi (API+DB kerak — alohida job, `dotnet-in-docker.sh api` yoki to'g'ridan-to'g'ri `dotnet run` Linux runner'da).
- Test ma'lumoti tozalash: har test o'z yaratgan yozuvini o'chirmaydi (backend testlaridagi kabi izolyatsiya yo'q — **shuning uchun noyob nomlar** shart, "Sinov" prefiksi bilan, dev bazani "iflos" qilmaslik uchun alohida `educenter_e2e` bazasi tavsiya qilinadi, lekin birinchi versiyada dev bazada ham ishlaydi).

## 4. Testlar
