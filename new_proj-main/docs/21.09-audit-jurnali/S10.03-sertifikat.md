## 1. Maqsad
TZ §42: kurs tugaganda talab tekshiruvi → sertifikat generatsiya → QR tasdiqlash → tarix. Hozir yo'q.

## 2. Hozirgi holat
S02.01 dan keyin `Group.Complete()` bor (guruh yopilishi). `Attendance`, `ExamResult` — talab tekshiruvi manbai. `AuthController.Login` naqshi — `[AllowAnonymous]` endpoint yozish uchun namuna (QR tekshiruv ham anonim).

## 3. Nima qilinadi
- **Domen** (migratsiya **`AddCertificates`**): `Certificate(OrganizationId, StudentId, GroupId, CourseId, Number (unique, "CERT-2026-000123"), IssuedAt, IssuedBy, VerificationCode (unique, 12 belgi, tasodifiy), PdfKey?)`.
- **Talab tekshiruvi:** `Course` ga (yoki alohida `CertificateRequirement(CourseId, MinAttendancePercent, MinFinalExamScore)`) — kurs darajasida sozlanadi (standart: davomat ≥ 75%, yakuniy imtihon ≥ 60%). `POST /api/certificates/eligibility/{enrollmentId}` — tekshiradi va sabab qaytaradi (agar rad bo'lsa).
- **PDF:** `QuestPDF` (MIT litsenziya) — shablon: markaz nomi/logo (S07.01 dan bo'lsa), student ismi, kurs, sana, QR kod (`QRCoder` yoki `QuestPDF` ichki QR), sertifikat raqami. `Api/Certificates/CertificateFileStorage.cs` (S09.06 dan keyin `IFileStore`).
- **Endpointlar:** `POST /api/certificates` (`certificates.issue` — SA `AllOrganization`, AD `MyBranches`; talab tekshiruvidan o'tmasa 409 + sabab, majburlab berish uchun `force: true` — audit'da belgilanadi), `GET /api/certificates?studentId=` (`certificates.view` — + Student `Self`, Parent `MyChildren`), `GET /api/certificates/{id}/pdf` (bearer), **`GET /api/certificates/verify/{code}` — `[AllowAnonymous]`**, faqat `{ valid: true, studentName, courseName, issuedAt }` yoki `{ valid: false }` (boshqa shaxsiy ma'lumot yo'q — `code` orqali qidiruv, ID orqali emas).
- **Frontend:** student profilida "Sertifikatlar" tabi (S04.03 tab ro'yxatiga qo'shiladi — ixtiyoriy), berish tugmasi (administrator, talab tekshiruvi natijasi bilan), yuklab olish (PDF). `/verify/{code}` ochiq sahifa (login talab qilmaydi) — tashqi odam (ish beruvchi) sertifikatni tekshirishi uchun.

## 4. Testlar — `CertificateTests.cs` (~9)
1. Talabga mos student → beriladi, PDF yaratiladi. 2. Talabga mos emas → 409, `force` bilan → beriladi (audit'da belgilangan). 3. `verify/{code}` to'g'ri kod → `valid: true`, minimal ma'lumot; noto'g'ri kod → `valid: false`; **shaxsiy ma'lumot sizmasligi** (javob JSON kalitlarini tekshiring). 4. Student/ota-ona faqat o'zinikini ko'radi. 5. Operator/teacher `issue` → 403. 6. Raqam va kod unique.
