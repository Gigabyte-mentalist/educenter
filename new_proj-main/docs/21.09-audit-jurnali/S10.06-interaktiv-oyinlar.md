## 1. Maqsad
TZ §26: Word Match, Sentence Builder, Speed Quiz, Missing Word (+ Listening Match, Grammar Battle, Pronunciation Practice, Daily Vocabulary Challenge — **keyingi iteratsiya**, bu qadamda birinchi to'rttasi). Vocabulary uchun Spaced Repetition (SM-2).

## 2. Hozirgi holat
Kontent manbai yo'q — `VocabularyItem` kabi jadval umuman yo'q. Kurs/daraja (`Course.LevelCategory`) bor.

## 3. Nima qilinadi
- **Kontent** (migratsiya **`AddVocabularyGames`**): `VocabularyItem(OrganizationId, CourseId?, LevelCategory, Word, Translation, ExampleSentence?, Difficulty (1-5))` — administrator/o'qituvchi qo'shadi (`vocabulary.manage` — yangi ruxsat, SA/AD/Teacher) yoki boshlang'ich to'plam seed qilinadi (ixtiyoriy, kichik CSV import).
- **Spaced Repetition (SM-2):** `ReviewCard(StudentId, VocabularyItemId, EaseFactor (decimal, standart 2.5), Interval (int, kun), Repetitions, DueAt, LastReviewedAt?)`. `SM2Calculator.Grade(card, quality 0-5) => updated card` (sof funksiya, algoritm mashhur — internetdagi standart formula, izohda manba ko'rsatiladi).
- **O'yinlar (backend — savol generatsiyasi va javob tekshiruvi, UI mantiqi frontendda):**
  | O'yin | Backend nima qiladi |
  |---|---|
  | Word Match | `GET /api/vocabulary/games/word-match?count=10` — `DueAt <= now` kartalardan tasodifiy so'z-tarjima juftlari + chalg'ituvchilar |
  | Missing Word | jumladan bitta so'z olib tashlanadi (`ExampleSentence`), variantlar |
  | Speed Quiz | ko'p tanlovli, vaqt chegarasi **frontendda** (server faqat savol/javobni biladi) |
  | Sentence Builder | so'zlar aralashtirilgan jumla, to'g'ri tartibni tekshirish |
  Har javob: `POST /api/vocabulary/games/{gameType}/answer` `{ itemId, correct/quality }` → `SM2Calculator` bilan `ReviewCard` yangilanadi, XP (S10.04: `Source.VocabularyGame`, kichik ball, +streak).
- **Ruxsat:** `vocabulary.play` — Student `Self` (mashq shaxsiy, xodimga natija ko'rsatilmaydi — Speaking bilan bir xil qaror). `vocabulary.manage` — SA/AD/Teacher (kontent).
- **Frontend:** `/practice/vocabulary` (yoki AI bo'limi ichida) — o'yin tanlash kartalari, har o'yin alohida komponent (`components/games/WordMatch.tsx` va h.k.), natija ekrani (XP, keyingi takrorlash vaqti).

## 4. Testlar — `VocabularyGameTests.cs` (~8)
1. `word-match` savol generatsiyasi (chalg'ituvchilar noyob, to'g'ri javob ichida bor). 2. Javob to'g'ri/noto'g'ri — `SM2Calculator` intervalni oshiradi/kamaytiradi (aniq raqamlar bilan). 3. XP beriladi (S10.04 bilan integratsiya). 4. `vocabulary.manage`siz kontent qo'sha olmaydi. 5. Boshqa studentning `ReviewCard`iga ta'sir qilmaydi.
6. Unit: `SM2Calculator` sof funksiya testlari (bir nechta `quality` qiymati bilan interval/ease ketma-ketligi).
